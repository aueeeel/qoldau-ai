# Qoldau AI

Локальный переводчик 50 жестов РЖЯ в казахские слова. Камера обрабатывается в браузере: MediaPipe Hands + Pose, 40 кадров, сравнение DTW со 983 эталонами в Web Worker. Обучать систему перед использованием не требуется.

Сайт: https://qoldau-ai-xi.vercel.app/

## Запуск

Установите Node.js и выполните в этой папке:

~~~powershell
npm start
~~~

Откройте http://127.0.0.1:3000/#translator . Включите камеру, нажмите «Показать жест», дождитесь отсчёта 3 секунды и покажите одно слово за 2 секунды. Видеообразцы доступны в разделе «Как показать слово» и словаре. Python для сайта не нужен.

## Что проверено

На 250 тестовых видео результат верный в 112 случаях (44.8%, отказы учитываются). Подробная точность каждого слова — в отчёте. Это прототип; точность на живой камере пока не измерена. Эталоны взяты из Slovo (РЖЯ), а не из проверенного корпуса жестового языка Казахстана.

Подробная архитектура, метрики всех 50 слов, ограничения, изменённые файлы и воспроизводимые команды: [GESTURE_REPORT.md](GESTURE_REPORT.md).

~~~powershell
npm ci
npm test
npm run evaluate
npm run evaluate:loso
~~~

## Новые примеры

Режим сбора и диагностики: http://127.0.0.1:3000/?dev=1#translator . Укажите код исполнителя, выберите слово, запишите примеры и экспортируйте JSON. Записи хранятся локально в IndexedDB. После проверки меток:

~~~powershell
npm run samples:import -- "C:/path/qoldau-gesture-samples.json"
npm run references:build
npm run evaluate:loso
~~~

Для проверки обобщения используйте разные коды для разных людей и один код для всех записей одного человека. Сам пример и его исполнитель исключаются из эталонов при оценке.

## Размещение

Сайт опубликован на Vercel: https://qoldau-ai-xi.vercel.app/ . Репозиторий подключён к проекту Vercel, поэтому новые изменения в ветке `main` автоматически публикуются. Исходные ролики для разработки, Python и большая старая ONNX-модель исключены из публикации; готовый кеш координат и 50 видеообразцов включены.

Источники и условия использования: [Slovo attribution](vendor/slovo/ATTRIBUTION.md), [MediaPipe models](vendor/models/README.md).

[Все 50 слов и прямые ссылки на видеообразцы](WORD_GUIDE.md).

В разделе «Текст → жест» можно выбрать одно из 50 слов или ввести русское/казахское название (например, «папа» или «Әке»). Видео поддерживает обычный повтор, замедление, показ по кругу и учебный просмотр: один раз в обычной скорости, затем дважды на скорости 0,5× с паузами. Рядом дана ссылка на бесплатный вводный курс РЖЯ Surdoclass с преподавателем; он используется как дополнительный учебный материал и не заявлен как источник всех 50 слов. Поддерживаются отдельные слова, а не перевод предложений.

Видеоплеер использует VP8/WebM с запасным MP4. Локальный сервер поддерживает HTTP Range для перемотки. После добавления или замены видео создайте браузерные копии командой `npm run examples:webm` (нужен Python с зависимостями из requirements-gestures.txt). Исходные MP4 сохраняются.
